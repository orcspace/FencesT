# FencesT — быстрый старт

1. Распакуйте ZIP целиком в постоянную папку и запустите **FencesT.exe**.
2. В левой колонке выберите группу или нажмите **«+ Новая группа»**.
3. На вкладке **«Оформление»** выберите материал и настройте прозрачность, скругление, размытие, цвет и размер значков.
4. Снимите **«Показывать названия приложений»**, чтобы оставить только значки.
5. Для своего фона нажмите **«Выбрать картинку…»**. Поддерживаются PNG, JPG и BMP. Изменения видны сразу.
6. Перетащите файлы, папки и ярлыки из Проводника в нужную группу. Оригиналы остаются на своих местах.

## Ежедневная работа

- Двойной щелчок по значку запускает приложение или открывает файл.
- За заголовок группу можно двигать; за нижний правый угол — изменять размер.
- Двойной щелчок по заголовку или стрелка сворачивает группу.
- Колесо мыши прокручивает длинную группу.
- **«Закрепить положение и размер»** защищает от случайного перемещения.
- В меню `…` доступны добавление, дублирование, скрытие подписей и удаление группы.
- На вкладке **«Ярлыки»** можно искать по имени/пути и убирать ссылки.
- **«Связать с папкой…»** показывает её актуальное содержимое. **«Отключить связь»** возвращает ручные ярлыки. Добавление и удаление файлов в такой группе выполняйте через Проводник.

## Горячие клавиши

**Win + Alt + F** — скрыть/показать группы. **Win + Alt + N** — новая группа.
Это стандартные сочетания. Для изменения откройте вкладку **«Настройки» → «Горячие клавиши»**, отметьте нужные **Ctrl / Alt / Shift / Win**, выберите основную клавишу и нажмите **«Применить клавиши»**. Они действуют сразу и сохраняются после перезапуска.

Для отключения выберите **«Отключено»**. Кнопка **«Вернуть стандартные»** восстанавливает исходные сочетания. Если комбинация занята или оба действия получили одинаковые клавиши, приложение сообщит об этом и сохранит прежние назначения. F12 недоступна, поскольку зарезервирована Windows.
Когда группа в фокусе: **F2** — оформление, **F5** — обновление, стрелки — выбор, **Enter** — открыть.
Удерживайте **Shift** при завершении перемещения, чтобы обойти привязку к сетке.

## Сохранение и восстановление

Настройки сохраняются автоматически в `%LOCALAPPDATA%\FencesT`. На вкладке **«Настройки»** есть экспорт и восстановление раскладки. В резервную копию входят оформление, позиции и пути; сами документы и картинки туда не копируются.

Закрытие окна настроек оставляет приложение в трее. Для полного выхода нажмите правой кнопкой на значок FencesT в трее → **«Выход»**.

## Особенности первой версии

Это независимые группы ярлыков поверх рабочего стола. Стандартные значки Windows не перемещаются и не исчезают автоматически. Стиль Liquid Glass создаёт стеклянный эффект из обоев, оттенка и бликов; живые окна за группой не преломляются. Проверка поведения на вашей сборке Windows 11 ещё нужна.
